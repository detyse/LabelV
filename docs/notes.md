# 开发笔记

整理当前版本中需要注意的行为和后续优化思路。

## 时间轴
- 在 TimelineWidget.update_position 中更新 current_frame 时，要同步重新计算 offset，确保播放头始终处在可见区域。
- 缩放或拖动时间轴时，使用当前可视帧范围限制 offset，避免滚动越界导致画面闪烁。
- 当程序自动滚动时间轴时，需要与用户手动滚动的状态区分开，防止重复触发刷新逻辑。

## 标签管理
- TimelineWidget.get_next_label_number() 需要跳过已经删除的编号，以防生成重复的序号。
- 标签面板和时间轴在标签的新增、删除与颜色变更上必须保持同步，避免出现孤立数据。
- 右侧标签列表支持双击播放对应片段，可用于快速校对每个标注。
